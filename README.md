# Sorting and Search Algorithm Benchmark

A C benchmarking program that compares common sorting algorithms and exercises multiple search strategies using numeric data loaded from a CSV file.

## Algorithms

- Insertion sort
- Bubble sort
- Selection sort
- Merge sort
- Quick sort
- Hybrid merge sort
- Binary search
- Ternary search

## Build and run

```bash
make
./algorithm_benchmark
```

The program reports execution times so the practical results can be compared with expected algorithmic complexity.
